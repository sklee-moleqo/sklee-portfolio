# AI 채점 추천

## 문제

서술형 답안을 AI가 채점해 점수와 의견을 추천하는 기능입니다. AI 응답은 수 초에서
수십 초까지 걸려서 화면 쪽에서 다음 문제가 생겼습니다.

- 버튼을 연타하거나 같은 답안을 다시 열면 같은 채점 작업이 여러 번 요청됨
- 서버 응답이 늦어지면 로딩이 끝나지 않아 채점자가 화면을 새로고침함
- 다음 답안으로 넘어간 뒤 이전 답안의 결과가 늦게 도착해 화면을 덮어씀
- 폴링 한 번이 네트워크 오류로 실패하면 살아 있는 작업까지 실패로 표시됨

## 해결

| 상황 | 처리 |
|---|---|
| 같은 답안 중복 요청 | 진행 중인 작업에 합류해 결과를 함께 받음 (작업 시작 1회) |
| 응답 지연 | 전체 대기 시간 상한을 넘으면 `timeout`, 화면은 다시 시도 버튼 표시 |
| 서버 부하 | 폴링 간격을 1초 → 2초 → 4초 → 8초(상한)로 늘림 |
| 답안 이동 | AbortSignal로 이전 호출을 취소, 늦게 온 결과는 화면에 반영하지 않음 |
| 일시 오류 | 연속 N회까지는 넘기고 계속 폴링 |

화면 쪽 원칙도 함께 정했습니다.

- AI 결과는 **추천**일 뿐이라 자동 저장하지 않습니다. 채점자가 "반영"을 눌러야 입력란에 들어갑니다.
- 로딩은 패널 안 버튼에만 표시해, 기다리는 동안에도 답안을 읽고 직접 채점할 수 있습니다.
- 점수를 반영한 뒤에도 추천 결과를 지우지 않아 비교하며 수정할 수 있습니다.
