# 002. 테넌트 조회 실패를 "없는 테넌트"로 보지 않기

- 상태: 채택

## 배경

미들웨어가 요청마다 접속 도메인으로 고객사 상태를 조회합니다. 처음에는 조회 결과가 ACTIVE가 아니면
모두 "등록되지 않은 도메인" 화면으로 보냈습니다. 그러자 백엔드 배포 중 잠깐 5xx가 나는 동안
**정상 고객사 전부에** 계약이 없는 도메인이라는 화면이 노출될 수 있었습니다.

또 ACTIVE 결과를 무기한 캐시했더니, 관리자가 고객사를 중지해도 프로세스를 재시작하기 전까지
화면에 반영되지 않았습니다.

## 결정

- 상태를 세 가지로 나눕니다. ACTIVE, NOT_FOUND(근거가 확실할 때만), UNAVAILABLE(그 외 전부).
- 5xx, 429, 타임아웃, 본문 파싱 실패는 모두 UNAVAILABLE이고 503 안내 화면을 보여줍니다.
- ACTIVE·NOT_FOUND는 30초만 캐시하고 UNAVAILABLE은 캐시하지 않습니다.
- 동시에 들어온 조회는 한 건으로 합치고, 캐시 크기에 상한을 둡니다.

## 결과

장애가 나도 사용자는 "잠시 후 다시 시도" 안내를 보고, 복구 즉시 정상 화면으로 돌아옵니다.
고객사 중지는 최대 30초 안에 화면에 반영됩니다. 실제 접근 차단은 백엔드가 API마다 합니다.
